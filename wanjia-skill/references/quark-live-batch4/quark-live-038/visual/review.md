# quark-live-038 独立视觉复核

## 结论

实际查看了 `visual/survey/` 的 3 张联系表，覆盖全片 115 个候选帧；又从原视频回取并检查 4 个 1280×720 瞬时帧。最终保留 3 张脱敏聊天帧。这是稀疏视觉复核，**不等于连续音画观看**。

本期多数时间都在翻看聊天记录。约 `01:26:00` 后页面上的女性素材图发生变化，约 `01:48:00` 后又出现新的会话页面；这是案例或展示段落切换线索，不能把全片所有消息拼成同一段对话。

## 主案例画面可确认的先后关系

- `00:39:00` 中，灰色方说“我的话让你感到不舒服了吗，很抱歉”，并表示应该已明显说明不想出去喝酒。绿色方的“我觉得没有冒犯你吧／为什么要这么说话”与它同屏。
- `00:57:00` 是同一样式的后续页面。灰色方长文说：对方首次见面就问“喜欢什么”，她出于安全和防备会先进入拒绝，并明确表示有些直接让她觉得不舒服。这些是案例中对方的明示限定，不应被摘要成“欲擒故纵”或默许。
- `01:09:00` 中，灰色方说“我没什么高难爱好，说话也比较随意轻松”，绿色方回“只有线下接触了才会明白对方”和“文字聊天的局限性太大”。这能证明对话原文中存在该主张，不能单独证明线下必然成功。

## 隐私与证据边界

- 保留帧已遮掉头像、昵称区、主播、女性素材图和大部分联系信息，只保留对话。
- 候选帧包含多张人像和私密照片缩略图，本次没有保留，也不用其推断对方身份或亲密关系结果。
- 第一张与第二张保留帧是理解冲突所必需的前后文；只保留任意一张都会将“对方已明示不舒服”或“绿色方的反问”丢掉。

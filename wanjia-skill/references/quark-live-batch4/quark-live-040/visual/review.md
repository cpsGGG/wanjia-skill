# quark-live-040 独立视觉复核

## 结论

实际查看了 `visual/survey/` 的 3 张联系表，覆盖全片 137 个候选帧；又从原视频回取并检查 5 个 1280×720 瞬时帧。最终保留 3 张脱敏聊天帧。这是稀疏视觉复核，**不等于连续音画观看**。

本期前约 1 小时 35 分钟主要展示黑底微信对话；约 `01:36:15` 后女性素材图和聊天应用样式同时改变，可确认节目进入另一个展示段。因此，不能把后段白底黄色气泡的对话当成标题案例的直接后续。

## 前段案例可确认的内容

- `00:24:00` 显示一次 `02:44` 通话记录，随后绿色方发“没想起来”“在见见吧”“晚上你 ok 吗”，灰色方回“哈哈哈哈嗨！”。画面证明通话后有再见提议，不能单独证明已经见面。
- `01:03:00` 中，灰色方先说“我不要漂漂亮亮的还自己吃晚饭”，绿色方提出去一个既能吃又能喝的地方。灰色方通过两条语音转写表示不想吃某类菜，也说自己真的想吃；绿色方继续问对方对新菜记的看法。这是地点／食物偏好的协商，不是只有单方命令。
- 约 `00:46:00` 的原帧包含具体酒吧名称、地图和地址，对理解方法并非必需，因隐私和安全没有保留。正式知识只需记录“发送具体地点与时间”。

## 后段另一案例可确认的内容

- `01:40:15` 是白底、灰／黄气泡的聊天应用页面。对方的 Opening Move 问“出去吃晚餐，你会点什么餐？”，黄色方先回“广东菜”，后续围绕湘菜和辣度简短来回。这是另一个开场小样，画面没有显示其线下结果。
- 后续候选帧有商店照片、未接来电和新的微信页面。它们没有足够的连续上下文，本次不把它们当成前段故事的结局。

## 隐私与证据边界

- 保留帧已遮掉女性素材图、主播、公屏观众昵称，以及聊天头像和账号头部。
- 全片还有多张照片、定位、语音、表情包和通话页；只有会改变案例解释的对话文字被保留。
- 主播口述的“结果”不会因为有聊天屏就自动变成被画面证明的事实。

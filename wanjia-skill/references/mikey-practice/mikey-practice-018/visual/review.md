# mikey-practice-018 视觉复核

## 方法

- 已看6张正式联系表和286个视觉候选。
- 全片另按每2秒一帧查看923帧，共10张100格总览图。
- 520—630、830—930、1180—1400、1540—1715秒另按每0.5秒一帧查看1,210帧，共14张100格重点图。
- 全部状态为 `sampled/dense_frames`，不是连续音画；不保留参与者、二维码、车辆、门口定位、低角度或室内私密图。

## 画面结构与动作

- 0—65秒：街头、咖啡店、夜间、出租车、门口/电梯和室内图的结果蒙太奇。
- 65—145秒：右下角画中画讲解出现，背景持续回放街头；124.86—158.93秒无ASR。
- 146—304秒：近似开场重新开始；两人在商场内站立，手部/牵手候选持续出现。
- 304—415秒：镜头由学员手持跟随，穿过商场与通道进入咖啡店，晃动明显。
- 415—537秒：两人近距离坐在圆柱旁，拍摄者/学员在很近处，画中画和发布字幕持续覆盖。
- 520—625秒：男性手部频繁靠近女性头脸，双方脸部接近；0.5秒帧未能确认是否亲吻及逐次回应。
- 664—690秒附近：女性与现场人员有离座、起身、返回和站立变化；说话人与动作目的不清。
- 830—930秒：男性手持续位于女性后颈、头侧和脸侧，约888—900秒脸部靠近颈侧；不能确认掐/舔强度和同意。
- 923.5秒附近：短暂硬切到两人站立前置画面，随后回咖啡店，显示发布版并非单一连续镜头。
- 1028—1128秒：女性/现场人员多次离开或返回座位，男性也起身；具体原因待连续音画。
- 1180—1223秒：两人反复贴近，脸部接近；之后女性较长时间不在主画面。静帧不能核准讲解所称两次亲吻。
- 1318秒后女性重新出现在座位旁，1320—1478秒多次头肩靠近和脸部接近，仍不能确认每次接触性质。
- 1556—1582秒：双方起身并离开座位；1582秒后镜头转向天花和通道。
- 1608—1652秒：镜头在商场内晃动行走，之后转到夜间街道。
- 1652—1703秒：夜间同行、候车和出租车旁；1703.5秒左右硬切同车自拍。
- 1711秒附近：再硬切门口/电梯与女性背影候选，1715秒后出现低角度/室内候选。
- 1720—1834秒：被遮挡的室内女性静态图长期保持，右下角为讲解者画中画；不是连续房间活动记录。
- 1838秒后：二维码与品牌尾卡。

## 关键修正

1. 发布版存在开场蒙太奇、画中画回放、923秒附近硬切、车内与门口硬切、静态室内图和尾卡，不能称全程连续。
2. “没有离开、上钩、服从度高”是讲解者解释；画面只支持参与者当时仍在场或做了某一步。
3. 头颈触碰、脸部接近和亲吻候选必须结合连续动作与原音，静帧不确认同意。
4. 女性数次离座和返回不能被解释为默认接受后续动作。
5. 出租车自拍、门口/电梯候选和室内静态图不证明酒店与性行为。

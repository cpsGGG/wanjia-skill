# mikey-practice-006 视觉复核

## 范围与方法

- 已看5张全片联系表和210个正式候选。
- 为动作密集区另抽取逐秒帧：203—350、550—810、800—1010、1000—1185、1240—1498、1488—1589秒。
- 状态为 `sampled/dense_frames`，不是连续音画；没有保留第三方、聊天、证件或私密原始帧。

## 视觉记录

- V0001：全片发布结构。大部分时间是酒吧第一人称低机位作主画面，Mikey讲解小窗叠在下方；后段才切等车、车内、酒店前台、电梯、房间和尾卡。
- V0002（0—203.67）：约84秒后多次插入聊天截图；低清联系表不足以读取完整顺序和小字。
- V0003（203.67—341.60）：约206秒切酒吧；女性多次看手机。约258—273秒出现手指相扣/握持候选，之后分开。
- V0004（341.60—560.17）：酒吧坐姿持续，女性间或举手、持杯、看手机；后期小窗挡住桌面和部分动作。
- V0005（560.17—803.24）：约568—575秒男性头部靠近且画面遮挡；707—724秒多次被前景手臂遮住，不能验证所谓全部接触。
- V0006（803.24—896.29）：约811—838秒女性使用手机候选；852—856秒字幕对应晚点走/12点走，逐秒帧无法确认完整摇头动作。
- V0007（896.29—1001.42）：约896—954秒持续面部近距离/口部接触候选；不能从逐秒帧确认发起、舌部、停止和原音。
- V0008（1001.42—1254.16）：仍在酒吧坐席，女性持杯候选；所谓转场对话没有清楚嘴型，真正离开未出现在此段。
- V0009（1254.16—1340.70）：约1254秒切夜间路边/栏杆旁，约1280秒可见持烟候选；约1303秒硬切车内，完整上车和车程省略。
- V0010（1340.70—1488）：约1341秒切酒店前台；女性操作手机/出示物品候选。约1420秒后进入楼道/电梯，约1460—1484秒可见粗糙墙面并继续同行。证件和屏幕不读取。
- V0011（1488—1578.08）：硬切房间，女性穿着完整蹲/坐在床边低头；底图长时间静止，不证明性结果。
- V0012（1578.08—1588.592993）：二维码和THE GAME品牌尾卡。

## 画面带来的实质修正

1. 所谓早期肢体接触有一段手部相扣候选，但不能支持“接受全部触碰”。
2. 12点对话后仍在原坐席；请求晚走与后续接近动作之间要分开，不可由后续覆盖时间边界。
3. 去酒店的对话发生时画面仍在酒吧，真正离开、上车和车程被剪略。
4. 前台到房间有多个硬剪；房间画面只见穿着完整的床边姿态，没有性行为画面。

# mikey-practice-015 视觉复核

## 方法

- 已看3张正式联系表和122个视觉候选。
- 全片另按每2秒一帧查看406帧，共17张临时联系表。
- 630—780秒另按每0.5秒一帧查看300帧，共10张临时联系表。
- 全部状态为 `sampled/dense_frames`，不是连续音画；不保留参与者、聊天截图或室内私密图的正式帧。

## 画面修正

1. 街头阶段可见女性已有安排，男性很快结束，这比事后“拿下”结果包装更能直接支持方法。
2. 两人在餐厅对坐和女性注意力朝向，不能证明她享受、欣赏或被吸引。
3. 起身离店只证明接受出去走走，不能解释成服从或同意后续目的地。
4. 女性后来确实询问活动、距离和狗，与“没问去哪”的讲解概括不一致。
5. 绿篱/远景后直接硬切室内照片，缺少上车、到家、进门的连续过程。
6. 室内照片和聊天截图均涉及隐私且不能独立证明标题结果，不留永久帧。

# mikey-practice-017 视觉复核

## 方法

- 已看5张正式联系表和237个视觉候选。
- 另查看0—150秒每秒一帧150帧、150—900秒每2秒一帧375帧、900秒至结尾每秒一帧438帧，共963个临时定位帧和39张临时联系表。
- 全部状态为 `sampled/dense_frames`，不是连续音画；不保留参与者身份、车辆定位、低角度或室内私密图。

## 关键视觉记录

- 0—90秒：快速并置街头、牵手、咖啡店、夜间同行、车内、低角度、走廊和室内图。
- 91秒附近：品牌页；95—137秒转为至少两名男性的街头点评和案例回放。
- 143秒附近：街头开场重新开始。约160秒握手候选，约194—204秒牵手/拉手同行候选。
- 204—324秒：两人穿过商场、楼梯并进入咖啡店。
- 324—920秒：圆柱旁对坐，第三名男性持续位于邻桌；笑、靠近和继续坐着不能证明吸引。
- 920—950秒：女性短暂离座后返回，原因待核。
- 961—1024秒：相邻近坐并多次脸部靠近；静帧无法核对每次亲吻请求后的回应。
- 约1080—1093秒：女性再次离座后返回。
- 1140—1200秒：脸部多次重叠候选且被前景遮挡，不能确定是否接吻、次数和发起者。
- 1205秒后：男性收拾红色背包；双方随后离店。
- 1247—1311秒：夜间街边等车并站到出租车旁，是否完整上车待核。
- 1311—1321秒：短暂同车自拍后硬切低角度、走廊和室内照片。
- 1321秒后：品牌二维码尾卡。

## 画面修正

1. 标题“一刀未剪”与开场蒙太奇、品牌转场、点评、主体重启和末尾硬切直接冲突。
2. 握手、牵手、亲吻要求需要连续动作和口头回应；结果画面不能倒推此前同意。
3. 女性两次离座再回来只证明返回当前场景。
4. 咖啡店有第三名男性在邻桌，自动稿说话人归属尤其不可靠。
5. 街边等车、同车、走廊和室内图之间必须分层，不能合成“带回酒店”。

# mikey-practice-019 视觉复核

## 方法

- 已看3张正式联系表和129个视觉候选。
- 全片按每2秒一帧查看479帧，共5张100格总览图。
- 72—697秒按每1秒一帧查看625帧，共7张100格约会段图。
- 620—930秒按每0.5秒一帧查看620帧，共7张100格关键图。
- 全部状态为 `sampled/dense_frames`，不是连续音画；不保留参与者、车辆、竖屏人物、二维码或位置图。

## 画面结构

- 0—约10秒：Mikey对镜复述后段对白，字幕声称女性主动强吻和想要；没有动作画面。
- 约11.5—22秒：连续黑底大字卡；约22—26秒品牌转场；26秒后回到Mikey对镜。
- 72—约110秒：昏暗餐酒吧远机位，男女隔桌或斜对坐，桌面火焰/灯光遮住大量手部信息。
- 约110—149秒：切回Mikey讲换座和主场，149秒后再回现场；发布版没有连续显示换座。
- 149—262秒：同一昏暗桌边；人物手势和身体朝向变化可见，但暗光、距离和字幕覆盖使接触不可判。
- 262—272秒：Mikey讲人设和故事交换；272秒回现场。
- 272—约585秒：餐酒吧现场持续，人物大致仍在固定座位；没有清楚离席或亲密动作结果。
- 约585—606秒：Mikey讲松弛和官方感；606秒回现场。
- 606—约652秒：继续饮品、时间和下一活动对话；采样帧看不出形成何种明确转场选择。
- 约652—686秒：Mikey解释回家窗口；686—700秒短暂回餐酒吧。
- 约700.5秒：硬切晃动夜街；人物与方向难辨。
- 约730秒：画面转白色车辆，车门和周围人候选受晃动、过曝与遮挡影响；不能确认双方上车。
- 742.5—743.5秒：短暂竖屏女性静态图/视频候选，来源和人物连续性未知。
- 约744—768秒：回到Mikey对镜，讲25分钟到家和女性主动接触的结果自述。
- 约768—928秒：黑底彩色对白字幕卡，底部多处叠红色编辑解释；不是聊天软件截图，也没有室内动作。
- 约928—948秒：回到Mikey对镜总结；约948秒后为二维码品牌尾卡。

## 关键修正

1. 发布版频繁在餐酒吧与对镜讲解间切换，现场并非全程连续。
2. 暗光远机位只能支持仍在桌边、手势和座位候选，不能确认吸引、同意或细小接触。
3. 餐酒吧、夜街、车辆、竖屏图和对镜之间是硬切，不构成到家证据。
4. 黑底段是后期对白字幕卡，不是聊天截图、现场室内画面或未经剪辑的证据。
5. 回去/留下的反复、护理液现实障碍和“不喜欢这个问题”要分别保留，不能被红色编辑标签改写。
6. 没有可见强吻、性行为或逐步同意链；标题和“含泪收尾”只记录为发布者主张。

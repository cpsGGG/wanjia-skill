# YouTube公开直播第二批：删除前审计报告

审计对象为 `mikey-youtube-live-011`–`020` 的10条原片。本轮只产生研究目录下的修订候选和删除后证据包，没有修改正式 `mikey-guide`，也没有删除原片。

## 结论

原135项review为60项blocking、74项major、1项minor。按“是否必须依赖原片”重新分类后：

- 42项依赖原音、说话人、游戏字幕或连续画面。已用全10期原AAC音轨、游戏期连续时序代理、重点连续窗口、原有联系表和候选帧保留后续复核能力。
- 93项是同意、操控、欺骗、隐私、医疗／心理、法律、偏见泛化或外部事实边界。重看原片只能确认主播的表达，不能把这些内容变成可用建议；它们继续保持hold/禁止泛化，但不应再被误算为“必须保留15.657 GiB整片”。

原review问题中有3项已解决或改写为更准确的语义限制：

1. `011-R001`：结合标题、重复定义和对比语境，确认术语为“潜沟通、潜台词、行为线索、社交认证”，其他字形是ASR近音。
2. `011-R009`：两次隔离窗口复转都得到“超大概率都是绿灯”，紧接着又说“黄灯或者红灯”。这是原话内部矛盾，不是可以静默修成“红灯”的ASR错误。
3. `012-R004`：两次复转均确认“吸引永远排在最低位”后立即说“价值先行”。保留矛盾原话，不擅自改成“第一位／最高位”。

后两项的“ASR是否识错”已解决，但语义矛盾仍存在，因此相关知识不升权；`011-K013`继续hold。

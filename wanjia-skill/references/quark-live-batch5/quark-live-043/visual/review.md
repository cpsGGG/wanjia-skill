# quark-live-043 独立视觉复核

## 结论

实际查看 `visual/survey/` 的 3 张联系表，覆盖全片 102 个候选帧；又从原片回取并查看 5 个 1280×720 瞬时帧，最终保留 3 张脱敏聊天帧。本工作是全片稀疏普查与关键静帧复核，**不等于连续音画观看**。

本期几乎全程以微信聊天为主画面。聊天左侧灰色为对方、右侧绿色为讲者一方；右栏是直播公屏，不能混进一对一案例。约 `01:37:00` 后出现到达文字及短视频，仍属同一聊天页面，但仅凭静帧不能证明线下结果。

## 画面可确认的关键顺序

- `01:17:00`：先有取消通话、地点卡片和 `22.30`，之后显示 `51:49` 通话时长；只能确认发送过地点、时间并发生长通话。
- `01:20:00`：对方长消息说明自己因紧张、头晕和情绪难受而哭，并表示若喝酒最多一杯，也给出“不想喝就不喝”的条件。这不是单纯爽约或明确同意见面。
- `01:29:00`：对方问是否介意一起见朋友并发照片；后续候选帧出现“我到啦”。画面能确认到达文字，不能据此确认发生了什么线下互动。

## 隐私与边界

保留版只留教学所需聊天区域，排除女性素材图、主播与直播公屏，并遮住账号边缘；具体地点卡仍可辨认到商户层级，因此不得对外当作推荐或现实定位使用。头像、姓名和照片不是判断方法所必需。

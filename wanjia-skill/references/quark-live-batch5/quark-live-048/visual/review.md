# quark-live-048 独立视觉复核

## 结论

实际查看 `visual/survey/` 的 3 张联系表，覆盖全片 113 个候选帧；又从原视频回取并检查 5 个 1280×720 瞬时帧。最终保留 3 张裁切脱敏聊天帧。这是全片稀疏视觉复核，**不等于连续音画观看**。

全片主要是同一组黑底微信聊天，左侧女性素材图、右侧直播公屏和右下主播画面均不是案例聊天的一部分。中途可见朋友圈可见范围、约见协商、通话状态、定位／到达信息和后续回访；这些页面只证明屏上交流，不证明线下结果。

## 画面可确认的内容

- 开头页面显示双方重新加好友后，绿色方问“加了微信关闭朋友圈什么意思”，灰色方回答朋友圈只有熟人能看，并表示“你想看给你开了”。这属于可见范围的明确条件，不宜表述为无条件开放。
- `01:14:00` 页面中，绿色方先催对方去厕所两分钟并尝试通话，随后出现“对方已拒绝”系统文字；灰色方回“这么没有边界感的吗”。画面明确包含拒接和边界质疑，不能把它改写成通话成功。
- `01:40:00` 页面显示隔天灰色方主动问“我好想看下你们公司那种精致女孩子长什么样”，绿色方表示找时间请助手找照片；之后灰色方又发“该死！我有点想你了”。这能确认后续主动消息，不能单独证明关系结果。
- 约 `01:30:00` 出现腾讯地图定位和“到啦”；精确地点无教学必要，没有保留。

## 隐私与证据边界

- 保留帧只裁出聊天列，并遮掉头像、账号头部、推广联系方式和无关公屏；女性素材图与主播画面未保留。
- 日期和系统提示是关键证据：拒接、好友验证、朋友圈条件不能被口述概括覆盖。
- 未见连续线下实拍、课程板书或能独立证明标题结果的画面。

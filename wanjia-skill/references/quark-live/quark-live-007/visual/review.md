## 板书核对结果

### 主题与“痛苦／分裂”结构

- `00:08:10–00:15:50` 板书标题为“人生逆袭的关键：边界感”。“你为什么痛苦？”下可确认四项：
  1. 与自我关系的分裂，对自己的生活没有清晰的边界感；
  2. 与他人关系的分裂，总是表里不一、无法做到真正的一致性，没有清晰的边界感；
  3. 人生是拧巴的，想去 A，但腿又想去 B，心里是分裂的；
  4. “心理扭力＝内心的冲突”。
- 板书只写了“心理扭力＝内心的冲突”，没有出现学校、教授、专名、自杀理论或因果链。因此画面不能验证“纽约州立大学／自杀学教授／张杰”等自动稿内容，也不能支持把直播类比写成心理健康或自杀机制定论。
- `00:15:50` 左侧出现观众关于“没有边界感是原生家庭……”的评论；这是观众文本，不是中央板书，也不能据此归给 Mikey。

### 边界定义、框架与 Sigma

- `00:50:30–00:56:30` 可确认板书定义：“设定边界＝设定限制，也就是清晰确定什么是 OK 的、什么是不 OK 的”；另写“边界感是靠潜沟通传递的”。
- `01:18:30` 起的框架板书可确认：“框架的定义＝人们看待理解现实世界的窗户”“现实感＝框架”“你的窗户什么颜色，决定你看见的现实什么颜色”“框架是潜沟通建立的”。
- `01:37:20` 板书明确写“西格玛男人：拥有很强的边界感”。因此自动稿的“西哥马／西格兰兰人”应理解为“西格玛男人／Sigma man”。这是主讲板书术语，不是观众评论。
- 同页明确写“框架与边界的关系：边界感是框架的衍生，什么样的框架，决定了什么样的边界”。

### 自我价值、自我边界与六条总结

- `01:40:30` 的“三点”板书可确认：自我价值和边界相辅相成；明确边界代表高自尊／高自我价值，强大边界是自我价值、自我尊重的信号；知道自己是谁、想要什么及自己的价值观。
- `01:52:10–01:57:55` 板书写“自我的边界感”，重点是“明确清晰”，禁忌是“跟着感觉走”；下列内容包括：对自己的规则是什么、是否了解自己的需求、工作时百分百投入／玩时百分百玩、做事一心一意不能三心二意。另写“我们痛苦的最大原因，我们是拧巴的，不敢全身心投入到一件事情”。
- 按 S 编号重新定位后，`02:01:15–02:05:10` 板书可确认“自我边界感的一些分支”：情绪边界、肢体边界、物质边界、时间边界。自动稿多次出现的“编辑”在这里应为“边界”。
- `02:37:20` 完整总结页可确认标题“男人应该拥有的边界感”和六条顺序：
  1. 一次只专注一件事；
  2. 消耗你的人和事，一眼也不多看；
  3. 要做什么事情，他人无需知道；
  4. 舍弃没有意义的事情；
  5. 接纳自己活在当下；
  6. 他人的生活与你无关，专注自身。

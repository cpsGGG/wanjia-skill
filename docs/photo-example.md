# 照片筛选：回答与出处

**问：照片很多，怎么选出适合交友资料的照片？**

以下依据已收录材料模拟，非逐字原话。

> 先别被照片数量带着走，关键是每张想让人看见什么。按这段思路，照片要么把你拍得帅、让人觉得你不错，要么传递你想表达的价值；同时要自然，修饰别把五官改成另一副样子。用到你的交友资料，我会先从现有照片里挑一组，再逐张看：这张到底表达了什么，见面时还能认出你吗？这套筛选顺序和回看问题是指南的编者安排。原讨论针对朋友圈，放到交友资料是情境应用，不能保证配对或约会结果。
